# 📁 Mini File Explorer

> **Сучасний кросплатформний файловий менеджер** на базі **C# 14 / .NET 10** та **Avalonia UI 11.2** з архітектурою MVVM, двопанельним режимом (Total Commander style), миттєвим фоновим пошуком (Everything style), підтримкою плаваючого сайдбару в стилі **Liquid Glass** та захистом критичних системних файлів.

---

## 🌟 Основні можливості

### 1. 🗂 Двопанельний та однопанельний режими (Total Commander style)
- **Перемикання 1 / 2 панелей** однією кнопкою або гарячою клавішею.
- Зручний `GridSplitter` для регулювання пропорцій між панелями.
- Клавіша **`Tab`** для миттєвого перемикання активної панелі з візуальним неоновим підсвічуванням.
- Швидкі операції копіювання (**`F5`**) та переміщення (**`F6`**) між лівою та правою панелями.

### 2. 🔍 Миттєвий Everything-style пошук
- Фоновий неблокуючий обхід директорій через BFS (`Queue<string>`), що **гарантує захист від переповнення стеку** (`StackOverflowException`).
- Пошук за маскою (`*.cs`, `*budget*`, `.pdf`) або підрядком.
- Скасування через `CancellationToken` у реальному часі без зависання UI.
- Відображення знайдених файлів у реальному часі зі статусом та прогрес-баром.

### 3. 🛡 Безпека та Zero-Crash архітектура
- **Запобіжник критичних системних файлів та директорій**:
  - Блокування випадкового видалення або переміщення системних папок (`Windows`, `Program Files`, `System Volume Information`, `$Recycle.Bin` тощо) та критичних файлів (`bootmgr`, `pagefile.sys`, `ntldr`, системні `.sys`/`.dll`).
  - Візуальний бейдж блокування `🔒 Захищено системою` у контекстному меню та деталях файлу.
- **Повна обробка винятків**:
  - Безпечна робота з обмеженими правами доступу (`UnauthorizedAccessException`).
  - Підтримка довгих шляхів (`PathTooLongException`) та спеціальних символів/кирилиці.
  - М'яке інформування користувача через ненав'язливий банер сповіщень замість падіння програми.

### 4. 👁 Панель попереднього перегляду (Preview Pane)
- Перегляд коду та текстових файлів (`.cs`, `.json`, `.txt`, `.md`, `.xml`, `.log`, `.html`, `.css` тощо).
- Перегляд зображень (`.png`, `.jpg`, `.jpeg`, `.bmp`, `.ico`, `.webp`) із розмірами та масштабуванням.
- Картка метаданих для бінарних файлів та документів.
- **Вбудований калькулятор хешу SHA-256**:
  - Асинхронне обчислення хешу з індикацією прогресу.
  - Копіювання хешу в буфер обміну.
  - Поле швидкої верифікації хешу з візуальним підтвердженням валідності.

### 5. 📊 Асинхронний розрахунок розмірів папок
- Фоновий підрахунок розмірів у `Task.Run` без блокування рендерингу чи скролу.
- Індикація розрахунку `calculating...` з плавним оновленням значень.
- Підтримка розмірів `B`, `KB`, `MB`, `GB`, `TB`.

### 6. 🎨 Сучасний дизайн: Liquid Glass & Low-Contrast Soft Theme
- **Плаваюча ліва панель (Liquid Glass / Frosted Acrylic Card)** з заокругленими кутами (`CornerRadius="14"`), напівпрозорою підкладкою та глибинними м'якими тінями.
- **Низькоконтрастна палітра (Low-Contrast Dark Slate)**:
  - Відмова від різкого чорного кольору (`#000000`) на користь м'яких графітових і сланцевих відтінків (`#18191C`, `#1E2024`, `#24272E`, `#252930`).
  - Текст м'яких приємних тонів (`#E3E5E8`, `#9DA5B4`, `#6B7382`).
- **Світла та темна теми**: плавне перемикання кнопкою у верхній панелі.
- **Кастомний пак іконок високої роздільної здатності**: диски з місткістю, папки, файли, кошик, закладки, індикатори сортування тощо.

### 7. 🧪 Стрес-тестування (Stress Test 10k)
- Вбудована перевірка продуктивності: генерація 10 000 файлів з тестуванням UI-віртуалізації Avalonia, плавністю скролу та відсутності витоків пам'яті.

## ⌨️ Гарячі клавіші (Hotkeys)

| Клавіша | Дія |
| :--- | :--- |
| **`Tab`** | Перемикання активної панелі в двопанельному режимі |
| **`Enter`** | Відкрити вибрану папку або запустити файл системною програмою |
| **`Backspace` / `Alt+Up`** | Перейти на рівень вгору (`..`) |
| **`F5`** | Скопіювати вибраний елемент у протилежну панель |
| **`F6`** | Перемістити вибраний елемент у протилежну панель |
| **`F7`** | Створити нову папку в активній панелі |
| **`Delete` / `F8`** | Видалити вибраний файл/папку (з підтвердженням) |
| **`Ctrl+Shift+C`** | Скопіювати повний шлях до файлу/папки в буфер |
| **`Ctrl+F`** | Перехід у поле пошуку Everything |
| **`Esc`** | Скасувати пошук / закрити модальне вікно |

## 🏛 Архітектура проекту (MVVM)

```
MiniFileExplorer/
├── Assets/
│   └── Icons/                   # Пак кастомних іконок Icons8 (PNG 64x64)
├── Models/
│   ├── FileItem.cs              # Доменна модель файлу / папки
│   └── DriveItem.cs             # Доменна модель логічного диска
├── Services/
│   ├── IFileSystemService.cs    # Інтерфейс безпечної взаємодії з ФС
│   ├── FileSystemService.cs     # EnumerateFileSystemEntries, захист, BFS-пошук
│   └── IconService.cs           # Кешування Bitmap іконок додатку
├── ViewModels/
│   ├── ViewModelBase.cs         # Базова реалізація INotifyPropertyChanged
│   ├── MainViewModel.cs         # Головна VM (теми, пошук, модалки, стрес-тест)
│   ├── FilePaneViewModel.cs     # VM файлової панелі (сортування, фільтр, навігація)
│   ├── FilePaneViewModel.Commands.cs # Файлові операції F5, F6, F7, Delete
│   ├── FileItemViewModel.cs     # Елемент списку (розмір, іконка, захист)
│   ├── FilePreviewViewModel.cs  # Панель прев'ю, зображення, SHA-256
│   └── SidebarItemViewModel.cs  # Сайдбар (диски, закладки, швидкий доступ)
└── Views/
    ├── MainWindow.axaml         # Головне вікно, плаваючий Liquid Glass сайдбар
    ├── MainWindow.axaml.cs      # Обробка гарячих клавіш вікна
    ├── FilePaneView.axaml       # Компонент файлової панелі (Details / Grid)
    └── FilePaneView.axaml.cs    # Фокус та кліки панелі
```

## 🚀 Запуск та компіляція

### Вимоги
- **.NET 10 SDK** (або .NET 9+)
- Windows 10/11, Linux або macOS

### Збірка та запуск розробника
```powershell
cd MiniFileExplorer
dotnet build
dotnet run --project MiniFileExplorer
```

### Публікація автономного дистрибутива (Self-Contained)
```powershell
dotnet publish MiniFileExplorer/MiniFileExplorer.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```
