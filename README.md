# Mini File Explorer

Сучасний кросплатформний файловий менеджер на базі C# 14 / .NET 10 та Avalonia UI 11.2 з архітектурою MVVM, двопанельним режимом у стилі Total Commander, фоновим пошуком файлів, плаваючим сайдбаром у стилі Liquid Glass, налаштовуваними колонками та захистом критичних системних файлів.

---

## Основні можливості

### 1. Двопанельний та однопанельний режими
- Перемикання між 1 та 2 панелями однією кнопкою.
- Регулювання пропорцій між панелями за допомогою вертикального роздільника.
- Клавіша Tab для перемикання активної панелі з візуальним індикатором фокуса.
- Швидкі операції копіювання (F5) та переміщення (F6) між активною та сусідньою панелями.

### 2. Регулювання ширини колонок у табличному перегляді
- Інтерактивні роздільники (GridSplitter) між заголовками колонок (Назва, Тип, Розмір, Дата).
- Зміна ширини колонок у реальному часі зі збереженням пропорцій і синхронізацією з рядками списку даних.
- Сортування за ім'ям, типом, розміром і датою в прямому та зворотному напрямках.

### 3. Автоматичний фоновий підрахунок розмірів папок
- Автоматичний розрахунок розмірів каталогів у фоновому потоці без блокування інтерфейсу користувача.
- Відображення прогресу обчислення в реальному часі.
- Детальний перегляд властивостей об'єкта з точним розміром файлів і папок.

### 4. Операції з файлами та безпека
- Перейменування файлів і папок за допомогою клавіші F2 або через контекстне меню.
- Створення нових папок за допомогою клавіші F7 або контекстного меню.
- Надійне копіювання повного шляху до файлу/папки в системний буфер обміну.
- Захист системних файлів і папок: блокування випадкового видалення чи переміщення критичних файлів операційної системи (каталоги Windows, Program Files, системні файли завантаження тощо).
- Модальні діалоги підтвердження для деструктивних операцій.

### 5. Попередній перегляд (Preview Pane)
- Перегляд текстових файлів та вихідного коду (.cs, .json, .txt, .md, .xml, .log, .html, .css тощо).
- Перегляд зображень (.png, .jpg, .jpeg, .bmp, .ico, .webp) з відображенням вихідної роздільної здатності.
- Інформаційна картка для бінарних файлів, архівів та каталогів з кастомними іконками.
- Вбудований інструмент перевірки контрольних сум:
  - Асинхронне обчислення хешу файлу з індикатором прогресу.
  - Копіювання хешу в буфер обміну.
  - Поле порівняння та валідації з очікуваним хешем.

### 6. Рекурсивний пошук та фільтрація
- Фоновий обхід директорій за алгоритмом BFS без небезпеки переповнення стеку.
- Пошук за назвою, розширенням або шаблоном (*.cs, pdf тощо).
- Можливість зупинки пошуку в будь-який момент через токен скасування.
- Швидка локальна фільтрація поточного каталогу в заголовку таблиці.

### 7. Сайдбар та закладки
- Плаваючий сайдбар з переліком підключених накопичувачів та обсягом вільного місця.
- Розділ закладок для швидкого переходу до часто використовуваних каталогів.
- Додавання поточного каталогу до закладок в один клік.
- Швидкий доступ до системних папок користувача (Робочий стіл, Завантаження, Документи, Зображення).

### 8. Стрес-тестування продуктивності
- Вбудований генератор 10 000 тестових файлів для перевірки віртуалізації списків Avalonia UI, швидкості сортування та стабільності споживання оперативної пам'яті.

## Гарячі клавіші

| Клавіша | Призначення |
| :--- | :--- |
| Tab | Перемикання активної панелі в двопанельному режимі |
| Enter | Відкрити папку або запустити файл асоційованою програмою |
| Backspace | Перейти на один рівень вгору (..) |
| F2 | Перейменувати вибраний файл або папку |
| F5 | Скопіювати вибраний елемент у сусідню панель |
| F6 | Перемістити вибраний елемент у сусідню панель |
| F7 | Створити нову папку в активному каталозі |
| Delete | Видалити вибраний файл або папку з підтвердженням |
| Ctrl+Shift+C | Скопіювати повний шлях до файлу або папки в буфер обміну |
| Esc | Закрити модальне вікно або скасувати активну операцію |

## Архітектура проекту (MVVM)

```
MiniFileExplorer/
├── Assets/
│   └── Icons/                   # Набір векторних та растрових іконок додатку
├── Models/
│   ├── FileItem.cs              # Модель файлу та каталогу
│   └── DriveItem.cs             # Модель накопичувача / логічного диска
├── Services/
│   ├── IFileSystemService.cs    # Інтерфейс файлових операцій
│   ├── FileSystemService.cs     # Робота з файловою системою, BFS-пошук, безпека
│   ├── IHashService.cs          # Інтерфейс обчислення контрольних сум
│   ├── HashService.cs           # Потокове обчислення хешу файлів
│   ├── IBookmarkService.cs      # Інтерфейс збереження закладок
│   ├── BookmarkService.cs       # Сервіс серіалізації закладок у JSON
│   └── IconService.cs           # Сервіс визначення та кешування іконок
├── ViewModels/
│   ├── ViewModelBase.cs         # Базовий клас ViewModel
│   ├── MainViewModel.cs         # Головна логіка вікна, тулбар, пошук, модалки
│   ├── FilePaneViewModel.cs     # Логіка панелі файлів, сортування, навігація
│   ├── FilePaneViewModel.Commands.cs # Команди файлових операцій
│   ├── FileItemViewModel.cs     # Елемент файлового списку
│   ├── FilePreviewViewModel.cs  # Панель попереднього перегляду та верифікації хешу
│   └── SidebarItemViewModel.cs  # Елементи сайдбару (диски, закладки)
└── Views/
    ├── MainWindow.axaml         # Розмітка головного вікна та сайдбару
    ├── MainWindow.axaml.cs      # Обробка глобальних гарячих клавіш
    ├── FilePaneView.axaml       # Розмітка файлової панелі, колонок та меню
    └── FilePaneView.axaml.cs    # Синхронізація ширини колонок та події списку
```

## Вимоги та збірка проекту

### Системні вимоги
- .NET 10 SDK (або .NET 9+)
- Windows 10/11, Linux або macOS

### Збірка та запуск
```powershell
cd MiniFileExplorer
dotnet build
dotnet run --project MiniFileExplorer
```

### Публікація автономного дистрибутива
```powershell
dotnet publish MiniFileExplorer/MiniFileExplorer.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```
